# Security Policy

JArmEmu is in maintenance mode: only bug fixes and security fixes are released.

## Supported versions

Only the latest release receives security fixes. Runtime requirement: Java 21.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability. Use GitHub's
[private vulnerability reporting](https://github.com/Dwight-Studio/JArmEmu/security/advisories/new)
(or contact the maintainers by email) with a description, the affected version and steps to reproduce.
